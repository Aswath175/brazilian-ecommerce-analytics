# Power BI Dashboard

This folder contains the interactive Power BI dashboard developed for the Brazilian E-Commerce Analytics Capstone Project.

## Dashboard Overview

The dashboard provides insights into:
- Sales performance
- Customer experience
- Delivery performance
- Product category analysis
- Business KPIs and trends

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
